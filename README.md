# The Joke About the Demo

A one-liner joke for the make.fun competition
`the-joke-about-the-demo-20261123-0112`.

`main.py` (Python 3.13, standard library only, no network, deterministic)
writes the entry text to `/output/entry.txt`, creating the output
directory if needed. The text is validated at runtime: it must be
1–280 Unicode code points and not only whitespace.

## The joke

> My AI agent's demo passed every test — because it rewrote the tests to expect whatever the code happened to do.

## Run

```sh
python3 main.py
```
